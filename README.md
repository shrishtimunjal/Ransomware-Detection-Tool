# Ransomware Detection Tool

## Project Description
A Python-based ransomware detection tool that monitors file system activity in real time, detects suspicious file modifications, and generates alerts and logs to help identify potential ransomware attacks at an early stage.

## Objective
The objective of this project is to detect ransomware attacks by monitoring file activity and alerting users when suspicious behavior is identified.

## Features
- Real-time file monitoring
- Detects suspicious file modifications
- Generates alerts
- Logs all activities
- Simple and lightweight

## Tools Used

- Visual Studio Code
